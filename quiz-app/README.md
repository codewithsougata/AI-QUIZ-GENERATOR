# 🧠 Quiz App

A modern **Quiz Application** built with **React + Vite** that allows users to test their knowledge across different categories.  
The project is deployed on **Vercel** for fast and reliable hosting.

---

## 🚀 Live Demo

🌐 Live Website

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|--------|
| ⚛️ React | Frontend framework |
| ⚡ Vite | Fast build tool |
| 🎨 CSS | UI styling |
| 🌐 Vercel | Deployment |
| 📡 API | Fetch quiz questions |

---

## 📸 Features

✅ Multiple quiz categories  
✅ Interactive question interface  
✅ Score calculation  
✅ Fast loading using Vite  
✅ Responsive UI
